# 深度验证与等级提升（补充条款）

适用：用户或项目明确要求「在授权目标内深入利用以提升影响等级证据」时。本条款与 [执行边界](../../SKILL.md)、[影响与收录](../impact-and-acceptance.md) 叠加使用：**只说明允许的验证深度，不放宽任何禁令**。

## 允许（无害验证优先，按序）

1. **能力面枚举**：读取平台自身的授权/权限枚举接口（权限矩阵、角色、能力清单、组织信息），用主体的实际权限证明能力，不需要执行敏感动作。
2. **既有材料复用**：优先用已采集的规模、维度、层级与配置证据完成影响论证，再考虑新增请求。
3. **边界对照**：同类对象/角色/字段的最小差异对照，用于区分「预期开放」与「实质越界」；拒绝项（401/403）与授权项同等重要，须一并记录。
4. **最小可逆写证明**：仅在只读证据不足以支撑影响、且**获得逐动作确认**时使用；单次、可回滚、先记录意图与回滚方式，完成后立即恢复并保存前后状态。

## 禁止（不因「提升等级」而放宽）

- 破坏性操作、持久化，以及超出单次可逆证明的写入/删除。
- 批量读取真实用户数据或个人信息；以「凑规模门槛」为目的的枚举与遍历。
- 使用在被测系统中发现的凭据、密钥、令牌访问任何目标。
- 越出已授权目标（主机、端口、路径及上下游关联资产）。
- DoS/压力、爆破、竞速与社工。
- 以改写标题、等级字段或引用无关案例来提升定级。

## 等级提升的正当路径

按序补齐并分别标注证据状态：**实际能力**（权限矩阵/授权 API/受控样例）→ **被突破的具体约束**（业务预期判定）→ **数据类别与规模的可信依据**（共同缺陷路径、逐对象限制、归属与总量）→ **平台条款映射**（收录与等级条款）。任一环节缺失时标注未知，按已证实影响保守定级。

## 记录要求

授权或动作许可变化须在任务记录中保存**新版本与影响范围**（时间、受影响条款、保留项、生效目标）。skill 安装目录不写入运行数据、账号、请求或目标清单；本文件仅为规则条款。
