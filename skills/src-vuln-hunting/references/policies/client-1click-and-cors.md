# 端侧应用 1-click 与 CORS/Origin 反射 定级/收录规则

来源：用户在会话中直接设定的规则（2026-10-17 记录端侧 1-click 与 CORS 口径；2026-10-18 追加并覆盖为“任何 Origin 反射 / ACAO 反射类发现均不报告”）。未提供官方条款文本、项目名与版本。适用对象是端侧应用——移动 App、PC 客户端、内嵌 WebView/小程序容器及设备侧客户端——中需要受害者一次交互即可触发的问题，以及服务端/网关侧的 CORS 与 Origin 反射类发现。与 [评级](../rating-standard.md)、[影响与收录](../impact-and-acceptance.md) 配合使用，并为这两类问题给出当前生效的等级上限与收录口径。

## Origin / ACAO 反射类：不报告（默认且强制，2026-10-18 生效）

- **定义（命中任一即属本类）**：`Access-Control-Allow-Origin` 回显请求 Origin（任意 Origin、精确回射、`null` 来源、后缀/子串匹配、通配与凭据并存）、`Access-Control-Allow-Credentials: true` 与上述任一组合，以及经该向量暴露的 `Expose-Headers`、内部服务名或拓扑头等附带信息。
- **处理**：一律记 submission_assessment=excluded，作为线索/proven_facts 保留；**不报告、不进入待提交清单、不进入交付报告与成果计数**。
- **不因场景放宽**：服务端、网关、内网系统与端侧应用同等适用；本类不再适用“组合出可定级影响链即可作为候选”的一般口径（唯一例外见下条）。
- **唯一例外**：该反射只是**另一独立影响**（例如已证明的 1-click 接管或代码执行）的组成部分，且该影响本身满足收录条件时，按该影响类别评估与报告；此时反射配置本身仍不得单独列为漏洞项。启用本例外前需与项目所有者确认。
- **已交付材料**：含本类内容时应从交付报告/清单中剔除（可保留内部线索与原始证据，但不在交付物中列示，也不在交付物中暴露相关内部信息）。
- **与其他规则的关系**：本文件为当前生效口径；与 [影响与收录](../impact-and-acceptance.md) 默认排除清单中“单纯 CORS 不收录”相比更严格（不再要求证明敏感数据读取）。技术验证方法见 [CORS 跨源读取](../by-type/cors.md)，该文只说明如何判断技术成立，不代表收录。

## 定级（端侧 1-click）

| 情形 | 等级上限 | 判定要点 |
|---|---|---|
| 端侧 1-click 漏洞（需受害者一次点击/交互才触发） | 中危或低危，不得给高危/严重 | 记录交互次数、载体（页面/链接/二维码/深链/文件关联）、触发身份，以及点击后真实获得的权限与数据 |
| 可直接接管 | 允许高危及以上 | “直接接管”指无额外前置条件即取得账号/会话/设备/客户端控制权，并有可复核证据 |
| 1-click + RCE | 允许高危及以上 | 单次交互即到达代码执行，且已证明执行上下文、执行身份与最终进程/系统能力 |

- 等级由点击后的真实终态决定，不由漏洞名称（XSS、CSRF、深链/协议劫持、文件关联、本地服务调用等）决定。
- 点击之后再升级的链条按最终真实终态定级，并逐节点标注已验证／证据支持／未知；未验证的连接不能用于支撑高危。
- 不足以给高危的反例：仅弹窗或仅证明脚本执行、仅读取局部字段、仅影响自身账号或自有设备、把一次交互写成零交互、只有“理论可接管”。
- 同一问题在服务端也成立时按服务端事实另行判断，不因客户端侧降级而忽略服务端影响；若服务端事实属于 Origin/ACAO 反射类，按上一节处理（不报告）。

## 收录

- Origin/ACAO 反射类一律不报告：见上节定义，不再逐案讨论是否“单纯”。
- 端侧 1-click 问题：要成为候选，需要组合出上面可定级的影响链（例如结合 1-click 达成接管或代码执行），并给出受保护数据或越权动作的实证；等级仍受“1-click 中低危”上限约束。若影响链的组成部分属于 Origin/ACAO 反射类，按上节处理：反射本身不报告，仅在例外确认后按最终影响类别评估。
- 不收录不等于停止观察：仍保留实际请求/响应、来源、自动身份、预检与读取边界证据，并按 [CORS 跨源读取](../by-type/cors.md) 区分“配置看起来宽松”与“真实私密读取”。

## 与项目规则的关系

- 本文件默认生效；当前项目发布更具体的等级/收录条款时，同时记录双方条款与来源，未确认前按更保守的一侧处理（不升级、不收录）。
- 本文件只收窄等级上限与收录范围，不放开任何测试动作许可：不因“要证明接管/RCE”而构造真实用户交互、扩大目标范围或执行未获准动作；需要更高等级证据时先利用已有材料或平台允许的无害验证方式。
