# 阶段 4：打磨（手感 + 画面 + 界面）

同样的玩法，打磨与否差别巨大。本阶段**不加新玩法**，只让已有的东西更爽、更好看、更清楚。

## 步骤 4.1：手感（Juice）

打开 `references/juice.md`，逐条对照：

1. 列出游戏里的所有**事件**（操作、得分、受伤、死亡、过关、按钮点击、新纪录）
2. 每个事件至少有 **1 个视觉 + 1 个音效** 反馈
3. 重要事件（死亡、大连击、过关）叠加 3 种以上反馈
4. 至少完成 juice.md 中"必做"的全部项目，"加分"项挑 3 个以上

## 步骤 4.2：画面

打开 `references/art-direction.md`：

1. 确认全游戏只用 `CFG.color` 里的颜色
2. 加背景层次（渐变 / 星点 / 网格 / 视差，选一种）
3. 玩家角色加"生命感"：待机呼吸缩放、移动时挤压拉伸、眼睛（两个小圆就够）
4. 截图检查：缩小到缩略图大小，还能一眼找到玩家吗？好坏物体分得清吗？

## 步骤 4.3：界面（UI）

- **标题界面**：游戏名（大、有动画）、一句话玩法说明、"点击开始"（闪烁或呼吸）、最高分
- **游戏中**：分数在顶部居中且字够大（≥ 64px）；其它 HUD 不超过 2 个
- **结算界面**：面板弹入动画、本局分数、最高分/新纪录庆祝、"点击再来一局"（延迟 0.5 秒才响应，防误触）
- 所有文字 ≥ 28px（手机上可读）；重要文字加阴影 `shadow: '#0006'`
- 文字不要压在游戏对象上；不要贴边（左右至少留 40px）

## 步骤 4.4：调数值

对照 `references/game-feel-numbers.md`，并做下面 3 个检查：

- **太难？** 让 smoke-test 随机乱玩 15 秒（`--seconds 15`）：随机操作就能拿高分 → 太简单；1 秒内就死 → 前期太难
- **太慢？** 前 5 秒内有没有发生值得看的事？
- **单调？** 30 秒和 60 秒的截图看起来不一样吗？
