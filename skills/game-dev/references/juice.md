# 手感清单（Juice）

"Juice" = 让每个操作都有夸张、及时、多感官的反馈。这是小游戏质量的最大来源。

## 反馈强度对照表

| 事件重要性 | 例子 | 反馈组合 |
|---|---|---|
| 轻 | 点击、移动、拾取小物品 | 音效 + 缩放弹跳 **或** 少量粒子(6–10) |
| 中 | 得分、击中敌人、连击 | 音效(变调) + 粒子(12–20) + 缩放 + 小震屏(4–8) |
| 重 | 死亡、Boss 击破、过关 | 顿帧(0.06–0.1) + 大震屏(15–25) + 闪屏 + 大量粒子(30–50) + 音效 |

## 必做 ✅

- [ ] **每个玩家操作**都有即时音效（`G.sfx`）+ 视觉变化
- [ ] **得分**：数字弹跳（`scale` 1.5 → 1，`outBack`）+ 粒子 + 音效
- [ ] **得分音效变调**：连续得分时 pitch 逐渐升高
- [ ] **死亡/失败**：`hitstop` + `shake` + `flash` + `burst`，**延迟 0.6–1 秒**再进入结算（让玩家看清发生了什么）
- [ ] **玩家角色**有待机动画（`scale = 1 + Math.sin(G.time*4)*0.04`）
- [ ] **按钮/开始提示**有呼吸或闪烁动画
- [ ] **新物体出现**不是凭空出现：从 0 缩放到 1（`outBack`），或从屏幕外飞入
- [ ] **物体消失**不是凭空消失：粒子爆开、或缩小淡出
- [ ] **结算面板**弹入动画
- [ ] **新纪录**有特别庆祝（不同音效 + 颜色 + 粒子）

## 加分（至少挑 3 个）

- [ ] **挤压拉伸**：跳起时 scaleX 0.8 / scaleY 1.2，落地时反过来，再 tween 回 1
- [ ] **拖尾**：记录最近 10 个位置，画成渐隐的圆
- [ ] **屏幕边缘警示**：危险从屏外接近时，边缘出现红色指示
- [ ] **慢动作**：关键瞬间（差一点死）短暂把 dt 乘 0.3
- [ ] **数字滚动**：分数从旧值 tween 到新值，而不是跳变
- [ ] **冲击波环**：碰撞处画一个快速扩大并淡出的 `D.ring`
- [ ] **朝向/倾斜**：移动时角色向移动方向倾斜（`rot = vx * 0.001`）
- [ ] **背景脉动**：得分时背景色短暂变亮
- [ ] **连击文字**：每 5 连击弹出"x5!"
- [ ] **难度升级提示**：难度阶段变化时屏幕中央闪现"加速!"
- [ ] **差一点提示**：擦边躲过时出现"好险!"并奖励分数

## 常用实现

```js
// 挤压拉伸
o.sx = 1.3; o.sy = 0.7;
G.tween(o, { sx: 1, sy: 1 }, 0.25, 'outElastic');
D.withTransform(ctx, o.x, o.y, { scaleX: o.sx, scaleY: o.sy }, () => D.circle(ctx, 0, 0, o.r, color));

// 冲击波环
const w = { x, y, r: 10, alpha: 1 }; this.waves.push(w);
G.tween(w, { r: 120, alpha: 0 }, 0.4, 'outCubic').then(() => (w.dead = true));
// draw: ctx.globalAlpha = w.alpha; D.ring(ctx, w.x, w.y, w.r, '#fff', 6); ctx.globalAlpha = 1;

// 分数滚动
this.shown = U.damp(this.shown, this.score, 12, dt);   // 画 Math.round(this.shown)

// 慢动作
update(dt) { dt *= this.slowmo ? 0.3 : 1; ... }
```

## 反面

- ❌ 震屏太频繁（每次小事都震）→ 只给中、重事件
- ❌ 粒子太多遮挡画面 → 单次 ≤ 50，生命 ≤ 1 秒
- ❌ 死亡后立刻切换到结算 → 玩家不知道怎么死的
- ❌ 所有音效同一个音高 → 用 `pitch: U.rand(0.9, 1.1)` 增加变化
