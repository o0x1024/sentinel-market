# 美术方向：构图与生命感

**画法**（线条、上色、质感、调色板）由画风决定，见 `references/art-styles.md`。本文件只管画风管不到的部分：**东西画多大、放哪里、怎么动**。

## 一、构图

1. **主角半径 28–40**（竖屏 720 宽），敌人和道具同一量级。太小的物体看不出画风，画面会像调试图
2. **游戏区填满屏幕**：可玩区域至少占屏幕的 70%。网格/棋盘至少占屏宽 80%，不要缩在中间一小块
3. **三层**：背景（`Art.bg`）→ 游戏世界 → UI。游戏物体不要进入 HUD 区（y < `UI.HUD_BOTTOM`）
4. **焦点**：同一时刻画面上最显眼的永远是主角。不要让背景装饰比主角还亮、还大
5. **留白要有意**：大片空白时，加场地边框（`Art.frame`）、地面格（`Art.tile(..., 'floor')`）或把游戏区放大，而不是随手撒装饰

## 二、形状语言（用 `Art.shape / Art.poly / Art.circle` 画自定义物体时）

| 形状 | 传达 | 用于 |
|---|---|---|
| 圆 | 友好、柔软、可收集 | 主角、奖励 |
| 三角、尖刺 | 危险 | 敌人、陷阱（或直接用 `Art.spiky / Art.bullet`） |
| 方块 | 稳定、静态 | 墙、平台（或直接用 `Art.block`） |
| 菱形、星形 | 珍贵 | 稀有奖励 |

好东西和坏东西要**形状 + 颜色**双重区分：`role: 'pickup'` 和 `role: 'enemy'` 的形状也要不同。

## 三、让画面"活"起来

画风已经给主角、敌人、道具加了表情、眨眼、呼吸、闪光、抖动。你还要做的：

- **主角跟随运动**：每帧把运动方向和速度传给 `Art.hero(ctx, x, y, r, { angle, speed, stretch })`，眼睛会看向前方，身体会拉伸
- **状态变化有动画**：出现时从 0 放大（`G.tween(o, { k: 1 }, 0.25, 'outBack')`，画的时候 `ctx.scale(o.k, o.k)`），消失时缩小或淡出，不要瞬间出现/消失
- **标题界面有演示**：让主角在标题页上做核心动作（见模板 title 场景）

## 四、截图自检

1. **缩略图测试**：缩小到手机图标那么大，还能一眼找到主角吗？
2. **画风测试**：和 `references/img/art-<画风>.jpg` 放在一起，像同一个游戏吗？有没有纯色圆/三角混在里面？
3. **空白测试**：有没有超过屏幕 1/3 的大片空白？
4. **重叠测试**：文字有没有压在物体上？
