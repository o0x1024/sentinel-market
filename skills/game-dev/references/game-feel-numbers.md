# 手感数值参考（逻辑分辨率 720×1280）

以下是"起步值"，写进 `config.js` 后再微调。单位：像素、秒。

## 通用

| 参数 | 推荐值 | 说明 |
|---|---|---|
| 玩家半径/尺寸 | 20–40 / 50–80 | 屏幕宽度的 4–10% |
| 触摸目标 | ≥ 80 | 按钮、可点击物 |
| 敌人与玩家尺寸比 | 0.7–1.3 | |
| 碰撞判定 | 视觉尺寸 × 0.8 | **对玩家宽容**：伤害判定缩小、拾取判定放大 1.2 倍 |
| 拾取判定 | 视觉 × 1.2–1.5 | |
| 一局时长 | 30–180 | |
| 首次失败时间 | ≥ 15 | 新手前 15 秒不应该死 |

## 平台跳跃

| 参数 | 值 |
|---|---|
| 重力 gravity | 2400–3200 |
| 跳跃初速 jumpSpeed | 900–1200（跳高 ≈ v²/2g ≈ 150–250px） |
| 最大下落速度 maxFall | 1400–1800 |
| 水平速度 | 350–500 |
| 土狼时间 coyoteTime | 0.08–0.12 |
| 跳跃缓冲 jumpBuffer | 0.1 |
| 松手截断 | vy *= 0.5 |
| 下落重力倍数 | 1.3–1.6（下落比上升快，更利落） |

## 躲避 / 弹幕

| 参数 | 值 |
|---|---|
| 敌人初速 | 200–350 |
| 加速度（每秒） | +3 ~ +8，设上限（如 900） |
| 生成间隔 | 1.2 → 最低 0.3–0.4 |
| 预警时间 | 0.4–0.8（危险出现前必须有提示） |

## 拖拽 / 跟随

| 参数 | 值 |
|---|---|
| 跟随平滑 `U.damp` k | 12–20（越大越跟手） |
| 拖拽最大拉距（弹弓） | 200–300 |
| 发射力度倍数 | 4–8 |

## 物理 / 弹射

| 参数 | 值 |
|---|---|
| 反弹损耗 | vy *= -0.6 ~ -0.8 |
| 空气阻力 | v *= (1 - 0.5*dt) |
| 地面摩擦 | vx *= (1 - 4*dt) |

## 谜题 / 网格

| 参数 | 值 |
|---|---|
| 格子大小 | 80–120（6×6 到 8×8） |
| 移动补间 | 0.08–0.15 秒 |
| 无效操作反馈 | 小震屏 4 + 低音 |

## 节奏 / 时机

| 参数 | 值 |
|---|---|
| "完美"判定窗口 | ±0.05 秒 |
| "好"判定窗口 | ±0.12 秒 |
| BPM | 100–140 |

## 动画时长

| 动作 | 时长 | 缓动 |
|---|---|---|
| 按钮按下回弹 | 0.15–0.2 | outBack |
| 物体出现 | 0.25–0.35 | outBack |
| 面板弹入 | 0.4–0.5 | outBack |
| 淡出 | 0.3–0.5 | outQuad |
| 分数弹跳 | 0.2–0.25 | outBack |
| 挤压拉伸恢复 | 0.25–0.4 | outElastic |

## 难度曲线公式

```js
// 平滑上升并有上限（推荐）
const d = 1 - Math.exp(-this.elapsed / 60);          // 0 → 1，60 秒约到 63%
const speed = U.lerp(CFG.speedStart, CFG.speedMax, d);

// 阶梯式（每 15 秒一档，适合配"升级!"提示）
const tier = Math.min(5, Math.floor(this.elapsed / 15));
```
